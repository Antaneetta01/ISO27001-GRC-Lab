## Purpose

This asset inventory documents critical organizational assets within the simulated smart IoT infrastructure environment used in the ISO27001-GRC-Lab project.

The inventory supports:

* asset management
* cybersecurity governance
* risk assessment
* compliance monitoring
* security control implementation
