# 🛡️ ISO27001-GRC-Lab

## 📌 Project Overview

This project is a Governance, Risk & Compliance (GRC) lab environment focused on applying cybersecurity governance concepts using ISO 27001:2022 and the NIST Cybersecurity Framework.

The lab simulates a smart IoT building infrastructure environment and demonstrates practical approaches to:

* Cybersecurity Risk Assessment
* Governance Documentation
* Security Policy Development
* Incident Response Planning
* Compliance Monitoring
* ISO 27001 Control Mapping

The project was developed to strengthen practical understanding of Governance, Risk Management, and Compliance (GRC) processes within a cybersecurity context.

---

## 🎯 Objectives

* Perform organizational risk assessments
* Develop governance and security documentation
* Identify and evaluate cybersecurity risks
* Define risk treatment strategies
* Create incident response procedures
* Map documentation to ISO 27001 controls
* Improve practical understanding of GRC workflows

---

## 📚 Frameworks Used

* ISO 27001:2022
* NIST Cybersecurity Framework (CSF)
