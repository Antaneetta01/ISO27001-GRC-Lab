# ISO27001-GRC-Lab

## Project Overview

This project is a Governance, Risk & Compliance (GRC) lab environment focused on implementing cybersecurity governance concepts using ISO 27001 and the NIST Cybersecurity Framework.

The lab simulates a smart IoT building infrastructure organization and explores practical approaches to:
- cybersecurity risk assessment
- governance documentation
- security policy development
- incident response planning
- compliance monitoring
- security control mapping

---

## Objectives

- Perform organizational risk assessments
- Develop governance and security documentation
- Map security controls to ISO 27001 and NIST frameworks
- Simulate cybersecurity incident response processes
- Improve practical understanding of GRC workflows

---

## Frameworks Used

- ISO 27001
- NIST Cybersecurity Framework
